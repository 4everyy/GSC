# 离线地图下载方案（客户端缓存版）

## 1. 背景与目标

### 1.1 现状

当前离线地图采用**服务端方案**（`docs/离线部署指南.md`）：

```
浏览器 ──HTTP──▶ tileserver-gl (Docker, :8081) ──▶ data/suzhou.mbtiles
```

- 地图数据（mbtiles）由运维人员预装在 Docker 容器中；
- 浏览器每次渲染都从 tileserver-gl 实时拉取瓦片；
- **局限**：前端无法感知"是否已下载""下载进度"，无法在浏览器侧管理缓存，断网时若 tileserver 未启动则地图完全空白。

### 1.2 新需求

态势大屏需要在不依赖 tileserver-gl 的前提下，也能呈现地图。即在**浏览器侧**完成瓦片的下载、缓存、渲染：

| 维度 | 要求 |
|------|------|
| 视觉 | ① 无网络时地图依旧可呈现；② 下载过程有进度条；③ 下载失败/成功有弹框 |
| 交互 | 从"系统配置"按钮进入 → 弹窗含两个 Tab："下载离线地图" / "本地" |
| 状态边界 | 未下载且无网→灰显瓦片 + 提示；下载中→进度条；部分缺失→缺失块灰显、已下载块正常 |

### 1.3 目标

在**保留现有 tileserver-gl 架构**的基础上，新增一层**浏览器端瓦片缓存**：

- 首次联网时，用户通过 UI 主动触发"下载离线地图"，前端按选定区域/层级从 tileserver-gl 批量拉取瓦片并存入 IndexedDB；
- 后续无论联网与否，前端优先从本地 IndexedDB 读取瓦片渲染，tileserver-gl 退化为"首次数据源"而非"运行时依赖"；
- 断网且本地有缓存 → 地图正常显示；断网且本地无缓存 → 灰显瓦片 + 提示。

```
│   OfflineMapDialog（系统配置 → 下载离线地图 / 本地）  ← 新增              │
│     ├─ 下载：按区域 bbox + zoom 范围批量预取                              │

│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘
                                   │ 首次联网下载
                                   ▼
                     tileserver-gl (Docker, :8081)
```

**关键设计点**：

1. **拦截点**：复用 MapLibre 的 `transformRequest`（`src/components/MapLibreContainer/MapLibreContainer.tsx:63` 已有此机制，当前用于 URL 重写）。扩展为"先查 IndexedDB 缓存，命中则返回本地 Blob，未命中则走网络并写回缓存"。
2. **缓存粒度**：按 `{sourceId}/{z}/{x}/{y}` 作为主键，Value 存原始 Blob（vector pbf / raster png）。Style JSON 与 Glyphs pbf 同样缓存。
3. **预下载 vs 懒加载**：
   - **懒加载**（默认开启）：浏览地图时按可视范围自动缓存访问到的瓦片，零配置、零等待。
   - **预下载**（本次需求重点）：用户在"下载离线地图"Tab 选定区域 + zoom 范围，前端批量拉取并入库，支持进度条与断点续传。

### 3.3 地图区域状态边界

中央地图区域（`MapLibreContainer`）根据缓存/网络状态呈现三种态：

| 状态 | 触发条件 | 视觉表现 |
|------|----------|----------|
| **未下载且无网络** | IndexedDB 无该视图瓦片 + `navigator.onLine === false` | 灰显瓦片（灰色棋盘背景）+ 中央提示"离线瓦片未下载，请前往 系统配置 → 下载离线地图" |
| **下载中** | 预下载任务进行中 | 底部悬浮进度条（复用 §3.2 进度条组件），地图可正常浏览已缓存区域 |
| **部分缺失** | 缓存有部分瓦片但当前视图存在未缓存块 + 断网 | 已下载块正常渲染，缺失块灰显（灰色占位），无弹窗打断 |

**实现要点**：
- "灰显瓦片"通过 MapLibre 的 `transformRequest` 在缓存未命中且断网时，返回一个固定的灰色 Blob（`data:image/svg+xml,...灰色占位`），避免 MapLibre 报错；
- "中央提示"复用现有 `maplibre-status--error` 覆盖层（`MapLibreContainer.tsx:333`），新增一个 `maplibre-status--offline` 变体；
- "下载中进度条"作为独立浮层组件 `DownloadProgressBar`，挂载在 `HomePage` 地图层之上。

## 4. 技术选型

| 组件 | 选型 | 理由 |
|------|------|------|
| 客户端存储 | **IndexedDB**（通过 `idb` 库封装） | 容量大（GB 级）、支持 Blob、异步非阻塞 |
| 瓦片拦截 | **MapLibre `transformRequest`** | 项目已用此机制（URL 重写），扩展为缓存拦截零改造 |
| 批量下载 | **fetch + 并发池**（p-limit 风格，并发 6-8） | 避免压垮 tileserver-gl；支持 AbortController 中断 |
| 进度通信 | **React Context + useReducer** | 下载状态全局共享（弹窗、进度条、地图态） |
| 配额查询 | `navigator.storage.estimate()` | 标准 Web API，展示已用/剩余空间 |
| 持久化 | `navigator.storage.persist()` | 请求持久化存储，防浏览器自动清理 |

> **不引入 Service Worker**：SW 会拦截所有同源请求，调试复杂，且现有 `transformRequest` 已足够精细控制瓦片请求。SW 方案作为 §8 备选。

### 5.2 IndexedDB 封装（tileCache.ts）

```ts
import { openDB, type IDBPDatabase } from 'idb'

const DB_NAME = 'gcs-tile-cache'
const DB_VERSION = 1
const STORE_TILES = 'tiles'
const STORE_TASKS = 'tasks'

let dbPromise: Promise<IDBPDatabase> | null = null
function getDB() {
  if (!dbPromise) {
    dbPromise = openDB(DB_NAME, DB_VERSION, {
      upgrade(db) {
        db.createObjectStore(STORE_TILES, { keyPath: 'key' })
        db.createObjectStore(STORE_TASKS, { keyPath: 'id' })
      },
    })
  }
  return dbPromise
}

export async function getTile(key: string): Promise<TileCacheRecord | undefined> {
  return (await getDB()).get(STORE_TILES, key)
}

export async function putTile(rec: TileCacheRecord): Promise<void> {
  await (await getDB()).put(STORE_TILES, rec)
}

export async function deleteTilesBySource(sourceId: string): Promise<void> {
  const db = await getDB()
  const tx = db.transaction(STORE_TILES, 'readwrite')
  let cursor = await tx.store.openCursor()
  while (cursor) {
    if (cursor.value.sourceId === sourceId) await cursor.delete()
    cursor = await cursor.continue()
  }
  await tx.done
}

export async function getCacheEstimate(): Promise<{ usage: number; quota: number }> {
  if (!navigator.storage?.estimate) return { usage: 0, quota: 0 }
  const { usage = 0, quota = 0 } = await navigator.storage.estimate()
  return { usage, quota }
}
```

### 5.3 下载引擎（tileDownload.ts）

核心算法：

1. **瓦片枚举**：由 bbox + zoom 范围，计算每层级行列号范围（标准 XYZ 瓦片公式）；
2. **并发池**：Promise 池控制并发数（默认 6），避免压垮服务端；
3. **断点续传**：下载前查询 IndexedDB 已有瓦片，跳过已缓存块；
4. **可中断**：暴露 `AbortController`，取消时已完成块自动入库。

```ts
/** 计算某 zoom 层级下，经纬度 → 瓦片行列号 */
function lonLatToTile(z: number, lon: number, lat: number) {
  const n = 2 ** z
  const x = Math.floor(((lon + 180) / 360) * n)
  const y = Math.floor(
    ((1 - Math.asinh(Math.tan((lat * Math.PI) / 180)) / Math.PI) / 2) * n,
  )
  return { x, y }
}

/** 枚举 bbox × zoom 范围内的所有瓦片坐标 */
export function enumerateTiles(
  bbox: DownloadTask['bbox'],
  minZoom: number,
  maxZoom: number,
): { z: number; x: number; y: number }[] {
  const tiles: { z: number; x: number; y: number }[] = []
  for (let z = minZoom; z <= maxZoom; z++) {
    const tl = lonLatToTile(z, bbox.west, bbox.north)
    const br = lonLatToTile(z, bbox.east, bbox.south)
    for (let x = tl.x; x <= br.x; x++) {
      for (let y = tl.y; y <= br.y; y++) {
        tiles.push({ z, x, y })
      }
    }
  }
  return tiles
}

/** 批量下载（支持并发、断点续传、中断） */
export async function downloadTask(
  task: DownloadTask,
  onProgress: (updated: DownloadTask) => void,
  signal: AbortSignal,
): Promise<void> {
  const allTiles = enumerateTiles(task.bbox, task.minZoom, task.maxZoom)
  // 断点续传：过滤已缓存
  const pending = []
  for (const t of allTiles) {
    const key = `${task.basemap}/${t.z}/${t.x}/${t.y}`
    if (!(await getTile(key))) pending.push({ ...t, key })
  }

  // 并发池（简化版，实际可用 p-limit）
  const CONCURRENCY = 6
  let index = 0
  async function worker() {
    while (index < pending.length) {
      if (signal.aborted) return
      const cur = pending[index++]
      try {
        const url = buildTileUrl(task.basemap, cur)
        const resp = await fetch(url, { signal })
        if (!resp.ok) throw new Error(`HTTP ${resp.status}`)
        await putTile({
          key: cur.key,
          sourceId: task.basemap,
          z: cur.z, x: cur.x, y: cur.y,
          blob: await resp.blob(),
          contentType: resp.headers.get('content-type') ?? 'application/octet-stream',
          cachedAt: Date.now(),
        })
        task.completedTiles++
        task.bytesDownloaded += resp.headers.get('content-length')
          ? Number(resp.headers.get('content-length'))
          : 0
        onProgress({ ...task })
      } catch (err) {
        if (signal.aborted) return
        task.failedTiles++
        onProgress({ ...task })
      }
    }
  }
  await Promise.all(Array.from({ length: CONCURRENCY }, worker))

  if (!signal.aborted && task.failedTiles === 0) {
    task.status = 'completed'
  } else if (signal.aborted) {
    task.status = 'paused'
  } else {
    task.status = 'failed'
    task.error = `${task.failedTiles} 块下载失败`
  }
  onProgress({ ...task })
}
```

### 5.4 MapLibreContainer 改造

当前 `transformRequest` 仅做 URL 重写（`MapLibreContainer.tsx:63`）。扩展为缓存拦截：

```ts
// 伪代码，展示改造点
async function cachedTransformRequest(url: string): Promise<{ url?: string; blob?: Blob }> {
  // 1. 判断是否为瓦片请求（/tiles/{z}/{x}/{y}.pbf 或 .png）
  const tileMatch = matchTileUrl(url)
  if (!tileMatch) return { url }  // 非瓦片请求，走原逻辑

  const { sourceId, z, x, y } = tileMatch
  const key = `${sourceId}/${z}/${x}/${y}`

  // 2. 命中缓存 → 返回本地 Blob
  const cached = await getTile(key)
  if (cached) {
    return { blob: cached.blob }
  }

  // 3. 未命中 + 在线 → 走网络，并异步写回缓存
  if (navigator.onLine) {
    fetchAndCache(url, key, sourceId, z, x, y)  // fire-and-forget
    return { url }
  }

  // 4. 未命中 + 离线 → 返回灰色占位 Blob，触发地图灰显
  return { blob: GRAY_TILE_BLOB }
}
```

> **注意**：MapLibre 的 `transformRequest` 同步返回 `{ url }`，不直接支持返回 Blob。需通过自定义 Protocol（`cooperative://`）或 `offline` protocol 插件实现。参考 `maplibre-gl` 社区的 `maplibre-gl-offline` 方案。落地时可能需要引入 `maplibre-gl` 的 `worker.addProtocol()` API 注册自定义协议，在 worker 中拦截请求并返回缓存的 ArrayBuffer。

## 6. 关键细节

### 6.1 灰显瓦片实现

缺失块灰显的两种方案：

| 方案 | 实现 | 优缺点 |
|------|------|--------|
| **A. 灰色占位瓦片** | `transformRequest` 缓存未命中且离线时，返回一个 256×256 灰色 PNG/SVG Blob | 简单直接；但每个缺失块都需返回，有轻微开销 |
| **B. 背景层灰显** | 地图容器背景色设为灰色棋盘，瓦片缺失处自然透出背景 | 更轻量；但无法区分"加载中"与"缺失" |

**推荐 A**：视觉明确，与"已下载块正常"形成对比。灰色 Blob 可预生成常量，无网络开销。

### 6.2 瓦片数与空间预估

```ts
// 瓦片数计算（已在 enumerateTiles 实现）
const count = enumerateTiles(bbox, minZoom, maxZoom).length

// 空间预估：按底图类型取平均单块大小
const AVG_TILE_SIZE = { dark: 20_000, satellite: 45_000 }  // bytes
const estimatedBytes = count * AVG_TILE_SIZE[basemap]
```

### 6.3 断点续传

- 下载前调用 `getTile(key)` 判断已存在则跳过；
- 中断/失败时已完成块已在 IndexedDB，下次重试自动续传；
- `DownloadTask` 状态持久化到 IndexedDB `tasks` store，刷新页面后可恢复进度。

### 6.4 配额与持久化

- 首次进入"下载离线地图"Tab 时调用 `navigator.storage.persist()` 请求持久化，避免浏览器在低空间时自动清理；
- 大批量下载前检查 `navigator.storage.estimate()`，超 80% 配额时警告。

## 7. 状态机

### 7.1 DownloadTask 状态流转

```
pending ──start──▶ downloading ──complete──▶ completed
                       │
                       ├──pause/abort──▶ paused ──resume──▶ downloading
                       │
                       └──error──▶ failed ──retry──▶ downloading
```

### 7.2 地图渲染状态（扩展 MapLibreContainer status）

现有 `status: 'loading' | 'success' | 'error'`（`MapLibreContainer.tsx:231`），新增：

```ts
type MapStatus = 'loading' | 'success' | 'error' | 'offline' | 'partial'
```

- `offline`：无缓存 + 断网 → 全屏灰显 + 提示；
- `partial`：有缓存但当前视图存在缺失 + 断网 → 已有块正常 + 缺失块灰显，不打断用户。

## 8. 备选方案：Service Worker

若 `transformRequest + 自定义 Protocol` 方案在落地时遇到 MapLibre worker 限制（如 vector tile 解码必须在 worker，自定义 protocol 注册复杂），可降级为 **Service Worker 全代理**：

- 注册 SW 拦截 `/tiles/*` 请求；
- SW 内部查 IndexedDB 缓存，命中则 `new Response(blob)`，未命中则 `fetch` 回源并写缓存；
- 优点：彻底解耦 MapLibre，所有 HTTP 请求统一拦截；
- 缺点：SW 生命周期复杂，调试困难，需处理版本更新与缓存失效。

**决策**：优先走 `transformRequest` 方案；若 1 周内验证 MapLibre worker 协议注册受阻，切换 SW 方案。

## 10. 风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| MapLibre worker 协议注册复杂 | P0 阻塞 | 预研 `maplibre-gl` `addProtocol` API；备选 SW 方案 |
| IndexedDB 大容量写入性能 | 下载慢 | 批量事务（每 100 块一次 commit）；`idb` 库已优化 |
| 浏览器存储配额限制（默认 ~2GB） | 下载中断 | `persist()` + 预检 `estimate()` + 超限警告 |
| satellite 栅格瓦片体积大（单块 ~45KB） | 全层级下载耗时数小时 | 限制 satellite 最大 zoom ≤ 16；推荐仅 dark 矢量全量下载 |
| 浏览器隐私模式 IndexedDB 受限 | 功能不可用 | 检测并提示"请退出隐私模式" |
