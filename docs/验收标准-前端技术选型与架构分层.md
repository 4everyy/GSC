## 六、已知偏差与说明

1. **`@` 路径别名**：OKR KR0.1 与项目说明书目录树标注 vite.config 含"别名 @"，但当前 `vite.config.ts` 无 `resolve.alias` 配置，源码也无 `@/` 引用（采用相对路径 + barrel 组织）。**建议**：验收时二选一——补充 `resolve.alias` + `tsconfig.app.json` `paths` 双端配置，或修订说明书/OKR 表述为"相对路径 + barrel 统一引用规范"。
2. **路由库**：开发规范 §1 提及 `react-router-dom`，当前以 `MainApp.tsx` 登录态门控分发实现（未安装路由依赖）。属规范前瞻性描述，不影响本任务验收，后续多页面扩展时引入即可。
