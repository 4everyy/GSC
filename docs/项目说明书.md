# 项目说明书（Project Specification）

> 本文件是本项目的结构与功能概览，须随代码结构变化实时更新。维护规范见 `docs/development-guide.md` 第 0 章。

## 1. 项目简介

**项目名称**：无人机集群控制地面站（Ground Control Station）

**定位**：面向无人机集群的地面控制端前端，提供态势展示、设备管理、任务规划、告警监控、地图交互与大屏可视化等能力。当前阶段以首页（HomePage）大屏态势界面为核心，展示飞行器、限制区、告警与设备管理面板等模块。

**技术栈**：

- 框架：React 19 + TypeScript
- 构建：Vite（HMR）
- 状态管理：Zustand（规划中）/ React State（组件局部）
- UI 组件库：Ant Design
- 路由：react-router-dom（规划中）
- 代码质量：Oxlint、ESLint、Prettier、Husky + lint-staged
- 测试：Vitest

## 3. 源码文件说明

### 3.1 应用入口

| 文件 | 职责 |
| --- | --- |
| `src/main.tsx` | 应用启动入口，将根组件 `<App />` 挂载到 DOM `#root`，并引入全局样式。 |
| `src/App.tsx` | 根组件，当前直接渲染 `HomePage`，后续作为路由与全局 Provider 的挂载点。 |
| `src/types.ts` | 全局通用类型定义，如 `AlarmColor`、`AlarmType`。 |
| `src/index.css` | 全局基础样式重置与通用规则。 |

### 3.2 页面（`src/pages`）

| 目录 | 职责 |
| --- | --- |
| `HomePage/` | 首页大屏态势主界面，作为容器编排顶部状态栏、地图工具栏、任务面板、告警面板、地图控件、紧急动作与飞行器/限制区渲染。通过 `activeAlarm` 状态联动告警高亮颜色。 |

### 3.3 公共组件（`src/components`）

| 组件 | 文件 | 职责 |
| --- | --- | --- |
| `StatusHeader` | `StatusHeader.tsx` | 顶部状态栏：标题、在线/起飞数量统计、告警徽标点击切换（受控，通过 `activeAlarm`/`onAlarmClick` 与父级联动）。 |
| `MapToolbar` | `MapToolbar.tsx` | 地图左侧工具栏；管理激活项，并通过 `mounted`/`visible` 状态控制设备管理面板的挂载与淡入淡出动画。 |
| `DeviceManagementPanel` | `DeviceManagementPanel.tsx` | 设备管理面板：设备列表、选中/悬停/展开状态、遥测详情（经纬度、姿态角等）展示。 |
| `MissionPanel` | `MissionPanel.tsx` | 编队任务面板：展示航线点与执行任务的飞行器。 |
| `AlarmInfoPanel` | `AlarmInfoPanel.tsx` | 告警信息面板：按告警颜色高亮，展示告警消息列表。 |
| `MapControls` | `MapControls.tsx` | 地图右侧控件：2D/图层切换、放大/缩小。 |

> 每个组件目录内含同名 `.tsx` 与 `.css`，样式与逻辑就近组织。

### 3.4 配置与假数据（`src/config`）

| 文件 | 职责 |
| --- | --- |
| `alarms.ts` | 告警类型配置 `ALARM_TYPES`：徽标图片 + 颜色（红/橙/蓝/绿）。 |
| `aircraft.ts` | 地图飞行器渲染配置：图标、CSS 类名与无障碍标签。 |
| `devices.ts` | 设备实体类型 `Device`、遥测类型 `DeviceTelemetry`，以及设备列表假数据 `deviceList`。 |
| `toolbar.ts` | 地图工具栏项 `toolbarItems`：标签、图标与三态背景（normal/hover/active）。 |

### 3.5 静态资源（`src/assets`）

| 目录 | 职责 |
| --- | --- |
| `images/home/` | 首页所需图片资源，通过 `index.ts` 聚合导出为 `homeImages`。 |
| `images/device/` | 设备管理面板图片资源，通过 `index.ts` 聚合导出为 `deviceImages`。 |

> 资源以业务域分目录，并统一以 `index.ts` 聚合导出，便于按命名引用。

## 4. 构建与脚本

| 命令 | 说明 |
| --- | --- |

| `npm run build` | 生产构建。 |
