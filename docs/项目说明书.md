# 项目说明书（Project Specification）

> 本文件是本项目的结构与功能概览，须随代码结构变化实时更新。维护规范见 `docs/development-guide.md` 第 0 章。

## 1. 项目简介

**项目名称**：无人机集群控制地面站（Ground Control Station）

**定位**：面向无人机集群的地面控制端前端，提供态势展示、设备管理、任务规划、告警监控、地图交互与大屏可视化等能力。当前阶段以登录页（LoginPage）与首页（HomePage）大屏态势界面为核心。

**技术栈**：

- 框架：React 19 + TypeScript
- 构建：Vite（HMR，Rolldown 构建）
- 状态管理：Zustand（`src/stores/`）
- UI 组件库：Ant Design
- 地图：MapLibre GL JS，经 `src/map-engines/` 抽象层（`MapAdapter` 接口）隔离引擎差异；离线瓦片经 `VITE_MAPLIBRE_STYLE_URL` 配置
- 实时数据：WebSocket（`src/features/realtime/`）
- 代码质量：Oxlint、ESLint、Prettier、Husky + lint-staged

> **分层约定**：`pages` 只做页面编排壳（页面组件 + 入口 CSS）；组件统一入 `components/`（跨页面公共件置顶，页面私有件按 `home/`、`login/` 业务域分组，跨层级不出现同名目录）；Hooks 统一入 `hooks/`；纯逻辑（无 React 依赖）入 `lib/`；页面级样式入 `styles/`（组件私有样式随组件同目录）；`features` 收独立业务域；`stores` 收跨页面共享状态；`assets` 按业务模块分目录（fonts 为全局共用），各模块目录以 `index.ts` 聚合导出。

## 3. 源码组织说明

### 3.1 应用入口

| 文件 | 职责 |
| --- | --- |
| `src/main.tsx` | 应用启动入口，将根组件 `<App />` 挂载到 DOM `#root`，并引入全局样式。 |
| `src/App.tsx` | 根组件：登录态校验与路由分发壳。 |

| `src/vite-env.d.ts` | Vite 环境变量类型扩展，声明 `VITE_` 前缀变量。 |
| `src/index.css` | 全局基础样式重置与通用规则。 |

### 3.2 页面（`src/pages`）

| 目录 | 职责 |
| --- | --- |
| `LoginPage/` | 登录页编排壳：组合 `components/login` 图标、`hooks/useLoginCanvas` Canvas 动效与 `styles/login` 样式集。 |
| `HomePage/` | 态势大屏主页编排壳：组合 `components/home` 各图层与面板、`hooks/` 飞行相关 Hooks、`lib/formationLayout`，入口 CSS `@import` 串联 `styles/home` 样式集。 |

### 3.3 组件（`src/components`）

| 组件 | 职责 |
| --- | --- |
| `AircraftFocusPanel/` | 飞机聚焦详情面板：展示选中飞行器的遥测与状态。 |
| `AlarmPanels/` | 告警面板（通用态）。 |
| `AreaPanels/` | 区域降落面板。 |
| `DeviceManagementPanel/` | 设备管理面板：设备列表、选中/悬停/展开状态、遥测详情（经纬度、姿态角等）展示。 |
| `ErrorBoundary/` | 全局错误边界：捕获渲染异常并展示降级 UI。 |
| `FlightActionPanels/` | 飞行指令面板族：返航、起降、航线飞行、集结点、编队飞行等指令下发 UI。 |
| `MapChrome/` | 地图外框装饰：状态栏、边框氛围。 |
| `MapLibreContainer/` | MapLibre GL JS 地图容器：初始化与销毁地图实例，`onReady` 暴露引擎实例。 |
| `PanelKit/` | 面板基础件：标题栏、滑动确认等可复用面板零件。 |
| `TargetListPanel/` | 目标列表面板：目标行、删除确认对话框。 |
| `TaskListPanel/` | 任务面板族：任务列表、创建、监控详情、专业版面板。 |
| `home/` | 态势大屏页面私有组件，按业务域分组：`aircraft`（飞行器图层）、`alarm`（告警）、`bottom-bar`（底部功能条）、`overlays`（飞行/模拟/六边形区域覆盖层）、`panels`（指令与任务面板编排）、`targets`（目标标注图层）、`zones`（任务区域图层）。 |
| `login/` | 登录页私有组件：SVG 图标集（`icons.tsx`）。 |

## 4. 构建与脚本

| 命令 | 说明 |
| --- | --- |
| `启动地面站.cmd` | 双击启动生产模式地面站：dist 缺失/过期时自动 `npm run build`，再以 `GSC_SERVE=preview` 拉起 Electron 桌面壳（vite preview 服务 dist）；控制台显示进度直至登录窗真正显示，失败时打印日志尾部并暂停。 |
| `npm run dev` | 启动 Vite 开发服务器（HMR）。 |
| `npm run build` | 生产构建（tsc + vite build）。 |
| `npm run preview` | 预览构建产物。 |
| `npm run desktop` | 开发者直启桌面壳（默认 vite dev，可配 `GSC_SERVE=preview`）。 |

> 提交前应执行：`npm run build`（由 Husky pre-commit 钩子自动运行）。
