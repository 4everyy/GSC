# 项目说明书（Project Specification）

> 本文件是本项目的结构与功能概览，须随代码结构变化实时更新。维护规范见 `docs/development-guide.md` 第 0 章。

## 1. 项目简介

**项目名称**：无人机集群控制地面站（Ground Control Station）

**定位**：面向无人机集群的地面控制端前端，提供态势展示、设备管理、任务规划、告警监控、地图交互与大屏可视化等能力。当前阶段以首页（HomePage）大屏态势界面为核心，展示飞行器、限制区、告警与设备管理面板等模块。

**技术栈**：

- 框架：React 19 + TypeScript
- 构建：Vite（HMR）
- 状态管理：Zustand（规划中）/ React State（组件局部）
- UI 组件库：Ant Design
- 路由：react-router-dom（规划中）
- 地图：双引擎架构 —— 百度地图 JavaScript API GL（BMapGL） + MapLibre GL JS，通过抽象层 `MapAdapter` 统一接口，支持运行时切换
  - 百度：环境变量 `VITE_BAIDU_MAP_AK`
  - MapLibre：环境变量 `VITE_MAPLIBRE_STYLE_URL`（离线瓦片服务地址）
- 代码质量：Oxlint、ESLint、Prettier、Husky + lint-staged
- 测试：Vitest

| --- | --- | --- |
| `StatusHeader` | `StatusHeader.tsx` | 顶部状态栏：标题、在线/起飞数量统计、告警徽标点击切换（受控，通过 `activeAlarm`/`onAlarmClick` 与父级联动）。 |

| `BMapContainer` | `BMapContainer.tsx` | 百度地图 GL 容器：动态加载 SDK、初始化与销毁地图实例，暴露 `onReady` 回调，支持加载中/错误态与 DOM 覆盖物叠加。坐标系为 BD09，内部做 WGS84↔BD09 转换。 |
| `MapLibreContainer` | `MapLibreContainer.tsx` | MapLibre GL JS 容器（与 `BMapContainer` 平行）：直接 `import` 方式加载、Style JSON 驱动底图、浏览器 Geolocation 自动定位、`onReady` 暴露 `MapEngineInstance`。坐标系为 WGS84，无需转换。 |
| `EngineSwitch` | `EngineSwitch.tsx` | 地图引擎切换按钮：在百度 / MapLibre 之间一键切换，视觉风格与 `MapControls` 一致。仅关心 `engine` 与 `onSwitch`，不感知 Container / adapter。 |

| `MapScale` | `MapScale.tsx` | 比例尺组件：通过 `adapter.getMetersPerPixel()` 计算每像素米数，渲染比例尺线段与文字。引擎无关。 |

### 3.5 地图引擎抽象层（`src/map-engines`）

> 核心设计：通过适配器模式（Adapter Pattern）将百度地图与 MapLibre 的差异封装在各自 Adapter 内，上层业务统一依赖 `MapAdapter` 接口，实现引擎无关与运行时切换。

| 文件 | 职责 |
| --- | --- |
| `types.ts` | 抽象接口与类型定义：`MapAdapter`（视图控制 / 覆盖物 / 事件 / 交互 / 生命周期）、`MapEngineInstance`（adapter + engine + raw）、`LngLat`（WGS84 统一坐标）、`MarkerHandle` / `PolylineHandle`（覆盖物句柄）、`MarkerOptions` / `PolylineOptions` / `CircleOptions`。所有方法以 WGS84 为输入输出，百度 Adapter 内部负责 BD09 转换。 |
| `BMapAdapter.ts` | 百度地图适配器实现：封装 `BMapGL.Map`，实现 `MapAdapter` 全部方法。内部维护 `wgs84ToBd09` / `bd09ToWgs84` 双向坐标转换、覆盖物 id→实例映射、事件绑定与解绑。 |
| `MapLibreAdapter.ts` | MapLibre 适配器实现：封装 `maplibregl.Map`，实现 `MapAdapter` 全部方法。WGS84 直用，无需坐标转换；折线采用"光晕底线 + 主线"双层渲染实现发光效果；通过 GeoJSON source + layer 模式管理矢量数据。 |
| `index.ts` | barrel 导出：上层统一从此文件导入 `MapAdapter` 类型与适配器类，避免直接引用具体引擎实现，降低耦合。 |

### 3.6 通用 Hooks（`src/hooks`）

| 文件 | 职责 |
| --- | --- |
| `useMapEngine.ts` | 地图引擎状态管理 Hook：持有 `engineType`（'baidu' \| 'maplibre'）与 `engineInstance`（`MapEngineInstance | null`）；切换引擎时自动调用 `adapter.destroy()` 销毁旧实例并清理覆盖物；提供 `onEngineReady` 回调供 Container 注入新实例。`engineType` 决定渲染哪个 Container，`adapter`（`engineInstance?.adapter`）供业务组件引擎无关地操作地图。 |

### 3.10 离线瓦片服务（`tileserver/`）

> 用于 MapLibre 引擎在离线/内网环境提供矢量瓦片与字体。详见 `docs/离线部署指南.md`。

| 文件 | 职责 |
| --- | --- |
| `docker-compose.yml` | tileserver-gl 容器编排：映射 8080 端口，挂载 `data/`、`styles/`、`fonts/` 目录。 |
| `config.json` | tileserver-gl 配置：数据源（mbtiles）、样式路径、字体路径、数据目录。 |
