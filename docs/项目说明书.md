# 项目说明书（Project Specification）

> 本文件是本项目的结构与功能概览，须随代码结构变化实时更新。维护规范见 `docs/development-guide.md` 第 0 章。

## 1. 项目简介

**项目名称**：无人机集群控制地面站（Ground Control Station）

**定位**：面向无人机集群的地面控制端前端，提供态势展示、设备管理、任务规划、告警监控、地图交互与大屏可视化等能力。当前阶段以登录页（LoginPage）与首页（HomePage）大屏态势界面为核心。

**技术栈**：

- 框架：React 19 + TypeScript
- 构建：Vite（HMR，Rolldown 构建）
- 状态管理：Zustand（`src/stores/`）
- UI 组件库：Ant Design
- 地图：MapLibre GL JS，经 `src/map-engines/` 抽象层（`MapAdapter` 接口）隔离引擎差异；离线瓦片经 `VITE_MAPLIBRE_STYLE_URL` 配置
- 实时数据：WebSocket（`src/features/realtime/`）
- 代码质量：Oxlint、ESLint、Prettier、Husky + lint-staged

> **分层约定**：`pages` 只做页面编排壳（页面组件 + 入口 CSS）；组件统一入 `components/`（跨页面公共件置顶，页面私有件按 `home/`、`login/` 业务域分组，跨层级不出现同名目录）；Hooks 统一入 `hooks/`；纯逻辑（无 React 依赖）入 `lib/`；页面级样式入 `styles/`（组件私有样式随组件同目录）；`features` 收独立业务域；`stores` 收跨页面共享状态；`assets/images` 按业务域分目录并以 `index.ts` 聚合导出。

## 3. 源码组织说明

### 3.1 应用入口

| 文件 | 职责 |
| --- | --- |
| `src/main.tsx` | 应用启动入口，将根组件 `<App />` 挂载到 DOM `#root`，并引入全局样式。 |
| `src/App.tsx` | 根组件：登录态校验与路由分发壳。 |
| `src/MainApp.tsx` | 主应用：登录态校验 + 页面路由（LoginPage / HomePage）。 |
| `src/vite-env.d.ts` | Vite 环境变量类型扩展，声明 `VITE_` 前缀变量。 |
| `src/index.css` | 全局基础样式重置与通用规则。 |

### 3.2 页面（`src/pages`）

| 目录 | 职责 |
| --- | --- |
| `LoginPage/` | 登录页编排壳：组合 `components/login` 图标、`hooks/useLoginCanvas` Canvas 动效与 `styles/login` 样式集。 |
| `HomePage/` | 态势大屏主页编排壳：组合 `components/home` 各图层与面板、`hooks/` 飞行相关 Hooks、`lib/formationLayout`，入口 CSS `@import` 串联 `styles/home` 样式集。 |

### 3.3 组件（`src/components`）

| 组件 | 职责 |
| --- | --- |
| `AircraftFocusPanel/` | 飞机聚焦详情面板：展示选中飞行器的遥测与状态。 |
| `AlarmPanels/` | 告警面板（通用态）。 |
| `AreaPanels/` | 区域降落面板。 |
| `DeviceManagementPanel/` | 设备管理面板：设备列表、选中/悬停/展开状态、遥测详情（经纬度、姿态角等）展示。 |
| `ErrorBoundary/` | 全局错误边界：捕获渲染异常并展示降级 UI。 |
| `FlightActionPanels/` | 飞行指令面板族：返航、起降、航线飞行、集结点、编队飞行等指令下发 UI。 |
| `MapChrome/` | 地图外框装饰：状态栏、边框氛围。 |
| `MapLibreContainer/` | MapLibre GL JS 地图容器：初始化与销毁地图实例，`onReady` 暴露引擎实例。 |
| `PanelKit/` | 面板基础件：标题栏、滑动确认等可复用面板零件。 |
| `TargetListPanel/` | 目标列表面板：目标行、删除确认对话框。 |
| `TaskListPanel/` | 任务面板族：任务列表、创建、监控详情、专业版面板。 |
| `home/` | 态势大屏页面私有组件，按业务域分组：`aircraft`（飞行器图层）、`alarm`（告警）、`bottom-bar`（底部功能条）、`overlays`（飞行/模拟/六边形区域覆盖层）、`panels`（指令与任务面板编排）、`targets`（目标标注图层）、`zones`（任务区域图层）。 |
| `login/` | 登录页私有组件：SVG 图标集（`icons.tsx`）。 |

> 组件私有样式（`.css`）与所属组件同目录；页面级公共样式集中在 `src/styles/`。

### 3.4 Hooks（`src/hooks`）

| 文件 | 职责 |
| --- | --- |
| `index.ts` | barrel 导出。 |
| `useExclusivePanels.ts` | 互斥面板状态管理（同一时刻仅一个面板激活）。 |
| `useFlightAnimations.ts` | 飞行动画（位置/朝向插值）。 |
| `useFlightInteractions.ts` | 飞行交互（选中、指令联动）。 |
| `useLoginCanvas.ts` | 登录页背景 Canvas 动效。 |
| `useDistanceMeasure/` | 距离测量 Hook + 渲染器。 |

### 3.5 纯逻辑（`src/lib`）

| 文件 | 职责 |
| --- | --- |
| `formationLayout.ts` | 编队布局计算（无 React 依赖，供编队飞行面板与图层共用）。 |

### 3.6 样式（`src/styles`）

| 目录 | 职责 |
| --- | --- |
| `home/` | `FlightMarkers.css`（飞行器标注）、`FlightPanels.css`（面板样式），由 `pages/HomePage/HomePage.css` 按层叠顺序 `@import` 串联。 |
| `login/` | `LoginBackground` / `LoginDrones` / `LoginForm` / `LoginPanel`，由 `pages/LoginPage/LoginPage.css` 串联。 |

### 3.7 状态与数据（`src/stores`、`src/api`、`src/features`）

| 目录 | 职责 |
| --- | --- |
| `stores/targetLinkStore.ts` | 目标关联状态（Zustand）。 |
| `stores/index.ts` | barrel 导出。 |
| `api/index.ts` | HTTP 接口层统一请求封装。 |
| `features/realtime/` | WebSocket 客户端（`wsClient.ts`）与通信协议（`protocol.ts`），详见 `docs/websocket-api.md`。 |
| `features/offline-map/` | 离线地图能力。 |

### 3.8 地图引擎抽象层（`src/map-engines`）

| 文件 | 职责 |
| --- | --- |
| `types.ts` | `MapAdapter` 抽象接口与类型定义（视图控制 / 覆盖物 / 事件 / 生命周期），坐标统一 WGS84。 |
| `MapLibreAdapter.ts` | MapLibre 适配器实现：封装 `maplibregl.Map`，GeoJSON source + layer 模式管理矢量数据。 |
| `index.ts` | barrel 导出：上层统一依赖抽象接口，不直接引用具体引擎。 |

### 3.9 配置与工具（`src/config`、`src/utils`）

| 文件 | 职责 |
| --- | --- |
| `config/index.ts` | 运行时环境配置：API 基址等，按环境变量读取。 |
| `utils/index.ts` | 通用工具函数（坐标换算、DOM 辅助等）。 |

### 3.10 静态资源（`src/assets`）

| 目录 | 职责 |
| --- | --- |
| `fonts/` | 自定义字体（MiSans 系列）。 |
| `images/home/`、`images/device/`、`images/task-panel/`、`images/measure/` | 按业务域分组的图片，各目录 `index.ts` 聚合导出（`homeImages`、`deviceImages` 等）。 |
| `videos/` | 视频资源（无人机预览等）。 |
