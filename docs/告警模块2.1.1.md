# 二、概述

# 2.1需求背景

地面站接收集群无人机、链路、任务、空域安全多源告警信息。操作员需要根据告警紧急程度快速

识别高危事件；同时避免海量重复告警刷屏干扰态势观察。需要一套分级展示、有序播报、支持聚合和

态势地图联动的告警管理体系，支撑集群作业场景应急处置。

# 2.2业务目标

按照紧急、警告、提示三级区分告警视觉与提醒力度，让操作员快速识别风险等级；

建立告警优先级机制，保证高危告警优先展示，不会被低优先级消息淹没；

通过同源告警聚合、重复告警抑制，解决大量同类告警刷屏问题；

告警条目与态势地图双向联动，一键定位涉事无人机设备，辅助快速处置；

区分已处理/待处理告警，支持历史告警回溯查询。

# 2.3术语定义

| 术语 | 释义 |
| --- | --- |
| Emergency（紧急告警，红色） | 最高风险，触发语音播报、地图闪烁强提醒 |
| Warning/Critical（警告告警，黄色） | 中等风险，界面滚动条持续播报 |
| Info（提示信息，蓝 / 灰色） | 普通通知，仅计数展示，不滚动播报 |
| 同源告警聚合 | 同一故障原因、多台设备同时触发告警，合并展示 |
| 告警抑制 | 单设备短时间重复触发同一条告警，只推送一次提醒 |

# 2.4需求范围界定

本次实现范围：

告警三级样式定义、计数展示、已处理/待处理筛选；

紧急告警语音播报、置顶强提醒；黄色告警右侧滚动栏循环播报；

告警优先级排序队列规则；同源告警聚合、短时重复告警抑制；

点击告警联动态势地图自动定位、设备高亮、聚焦视图；

告警处理状态标记，统计计数同步更新。

本次不开发：告警自动委派、故障趋势预测功能。

# 三、核心业务流程

系统接收后端推送各类告警消息，根据告警等级分配展示通道；

新告警按照优先级队列排序，紧急告警置顶，黄色告警进入滚动播报队列；

同源重复告警自动聚合/抑制，避免列表刷屏；

操作员查看滚动告警或展开对应告警面板，点击告警条目，态势地图自动定位涉事设备，设备高

亮，进入聚焦视图；

操作员已处置的告警，改告警条目流转存入对应的「已处理」列表中，对应计数实时更新。

# 六、通用UI与交互规范

# 6.1文本截断与Tooltip悬浮提示机制

截断规则：单行文本超出容器宽度，文本末尾显示省略号...；仅被截断文本触发悬浮提示。

触发条件：鼠标悬停在截断文本区域持续0.5s弹出气泡。

展示样式：气泡优先展示在光标右上方/正上方；气泡内展示完整告警文本；超长文本设置气泡最

大宽度，内容自动换行。

消失逻辑：鼠标移出文本区域，或点击界面任意位置，Tooltip立即关闭。

Tooltip互不冲突：悬浮气泡不会遮挡告警操作按钮。

# 6.2告警操作入口布局规范

列表行交互：鼠标悬浮告警条目时条目高亮；截断文本同步唤起Tooltip展示全文。

聚合告警操作：展开对应的告警列表。。

Emergency紧急告警特殊交互：语音播报+顶部置顶展示（仅保留最新一条）+红色呼吸闪烁动

效。

处置入口：每条告警条目右上角放置「×」关闭按钮，点击标记告警为已处理。

# 6.3告警处置闭环与生命周期

告警完整生命周期：告警产生→待处理→已处理

产生：系统监测无人机、任务、态势异常，生成告警；依据告警等级推送至告警区、滚动列表对应

视图。

处置：操作员点击告警条目右上角「×」按钮；告警状态流转为【已处理】；

聚合告警处置：操作员将聚合告警点开后，具体单设备告警条目出现，点击对应告警条目右上角

「×」按钮，其告警状态流转为【已处理】，聚合告警计数对应减一。

边界约束：已处理告警不会被删除，在对应的历史告警面板可检索查看；

# 七、非功能性需求

时序稳定性：大量告警并发推送场景，队列排序、聚合规则不混乱，无消息丢失；

交互体验：所有文本截断场景，hover悬浮展示完整告警内容；

状态一致性：告警已处理/待处理状态、图标计数、列表筛选三者保持同步；

性能约束：在线告警条目上限XX条内，滚动播报、地图联动无明显卡顿（上限数值和开发对齐后

填入）；

容错性：异常告警字段缺失、设备离线场景，页面友好展示，不出现崩溃、白屏；

# 八、重要风险说明

本需求文档仅定义业务规则、交互表现、验收标准；底层消息队列、消息降噪、语音并发、地图渲

染等技术实现方案，由研发团队进行方案设计与风险评估；若现有底层架构无法支撑部分能力（告警聚

合、高频消息抑制等），研发需提前同步限制、降级方案，双方共同确认取舍；

所有需求变更，必须通过更新文档版本+修订记录进行留存，口头调整不纳入正式需求。
