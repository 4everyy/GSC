# 一、项目背景

随着无人机作业场景的复杂化，地面站态势大屏作为飞手与后台指挥中心的核心交互界面，承担着实时态势感知、多设备协同管控及异常告警处理的关键职责。

该版本主要是改善多设备密集聚簇显示、图层精细化管理以及告警与地图的联动交互体验，以满足复杂作业环境下的高可靠性需求。

# 全局说明与非功能性需求

## **1、****交互与视觉规范**

异常反馈：所有网络请求失败、下载中断或加载超时，必须有明确的Toast或弹窗提示，禁止静默失败。

状态指示：设备在线、离线、告警等状态需通过图标颜色严格区分；加载过程中的UI控件需显示Loading状态。

快捷键支持：全局支持Esc键退出聚焦视图或关闭当前弹窗。

## **2、异常处理原则**

链路丢失：设备断链时，历史轨迹需在断点处停止，严禁绘制虚假连续轨迹，直至链路恢复。

数据缺失：离线的设备，图标需统一置于地图边缘的“未知位置”区，禁止在地图中心随机放置。

# 三、名词解释

瓦片 (Tiles)： 地图切片技术，将大地图切割成无数小图片拼接而成，用于加速加载及支持离线缓存。

聚簇 (Clustering)： 当多个设备图标在地图上因缩放级别或设备密集而重叠时，自动聚合为一个带数字的簇图标，以保持界面整洁。

聚焦视图 (Focus View)： 针对单台设备的专属视图模式，地图自动平移缩放至该设备为中心，并展示云台监控等专属控制面板。

遥测 (Telemetry)： 无人机实时回传的状态数据，包括经纬度、高度、速度、电量、飞行模式等。
