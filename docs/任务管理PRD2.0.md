# 二、概述

# 2.1需求背景

本模块为AI智能体集群地面控制站核心任务创建模块，支持区域巡检作业任务、目标打击任务；操作员

通过向导式多步骤配置，完成任务参数编辑、设备分配、航线生成，最终下发任务给无人机集群执行。

# 2.2业务目标

支持操作员完整完成区域侦察任务全流程创建；

参数校验拦截非法输入，防止生成无效任务；

向导步骤保存/回退逻辑清晰，支持中途放弃创建；

任务创建完成后可在任务列表查看、删去、装订、重规划、重执行、启动停止。

# 2.3需求范围界定

本次实现范围：

任务创建（一键生成、高级设置采用5步向导）；

任务列表、任务详情执行操作（删除、装订、开始、停止、重规划、重执行）。

本次不实现：

不做任务定时调度（定时下发任务）；

不做多人协同编辑同一个任务；

任务下发之后机载侧执行异常、失联后的自动重试，不属于本前端模块范围，由后端&机载负责。

# 三、用户场景

操作员支持创建区域巡检任务，配置参数、分配无人机，生成并保存航线，后续装订下发执行。

支持对已有任务做重规划修改；支持中途放弃创建，未填参数不保存。

无可用无人机时，流程阻断，无法继续创建任务

# 四、技术可行性简述

航线生成、参数校验、威胁区判断依赖后端路径规划等接口。

约束：页面刷新/关闭不保留草稿；任务创建成功不等于机载一定能正常执行。

风险：受上游接口交付与稳定性影响；最终可行性以研发技术方案为准。

# 六、非功能需求

页面加载：任务配置页面加载≤2s；航线卡片渲染，设备≤20台时无明显卡顿；

参数输入校验：所有数字输入框实时校验，非法数值不能提交；

兼容性：仅适配地面站指定PC客户端；

异常：后端接口报错时，前端给出明确toast提示，不允许页面崩溃。

# 七、全局通用规则

关闭弹窗/页面右上角X按钮：中途点击X关闭当前任务创建流程，当前所有已填写参数全部丢

弃，不保存草稿，直接返回上级页面。

返回上一步按钮：需求描述中“返回上一步，当前页面所选信息不保留”，定义：返回上一级向导步

骤，本步骤填写全部数据清空；上一步骤已提交保存的数据保留不变。

按钮置灰通用：当必填项缺失、参数非法、接口加载中，【保存下一步/一键创建】按钮置灰不可

点击。

Toast提示统一：失败toast为红色，成功toast绿色；toast停留3s自动消失。

页面刷新：任务创建中途刷新页面，所有未提交的配置全部丢失，无草稿留存。

设备状态过滤：向导设备列表，失联、低电量、故障无人机默认置灰不可勾选。

任务状态流转：开始执行，执行完成，执行失败需要对应toast提醒。

权限：本版本不做细粒度权限控制，登陆操作员均可访问全部任务创建功能。

# 八、风险与约束说明

本任务创建模块强依赖后端接口、态势地图组件、无人机设备状态服务；若上游接口返回异常、超

时、数据错误，本模块会出现提示、按钮置灰等保护表现，不属于产品需求缺陷，需要后端协同定

位处理。

本版本不做任务创建草稿持久化：页面刷新、关闭向导页面，未完成提交的任务配置全部丢失；操

作员需要完成全流程向导并点击“完成”，任务数据才会持久化保存至服务端。

向导步骤的“返回上一步”逻辑：仅清空当前步骤填写数据，不回退已经提交保存的上一步数据；该

逻辑已在需求中明确，研发实现必须严格对齐本定义。

任务创建完成只代表服务端生成任务数据；任务能否成功装订、下发、机载执行，受无人机硬件状

态、机载算法、通信链路影响，不在本地面站创建模块需求范围之内。

数字参数最大/最小阈值，本PRD给出默认数值，最终阈值以后端约束为准；前端仅做基础拦截，

后端必须做二次参数校验，防止非法参数入库。

本需求为初稿，后续如果业务变更、算法/硬件能力变更，需要走需求变更评审流程修改本文档；
