# 注释模板速查（按文件类型）

> 依据《React项目文件注释规范》整理，写代码时直接复制套用。
> 核心顺序：**功能是什么 → 关键输入 → 输出 → 注意事项**，每项一句话。

---

## 1. 组件（.tsx / .jsx）

```tsx
/**
 * @file 视频通道卡片
 * @description 单路视频画面：信息条/遥测面板/摇杆/抓拍录像截图工具列，供视频监视页使用
 * @author 张三
 * @date 2026-10-07
 */

/**
 * @description 视频通道卡片组件
 * @param {VideoChannel} channel - 通道数据（名称/电量/遥测等）
 * @param {boolean} [expanded] - 页内展开态，默认收起
 * @param {() => void} [onClose] - 关闭画面回调
 */
export function VideoChannelCard({ channel, expanded, onClose }: Props) {
  // 空数据时直接提示，不渲染列表
  if (!channel) return <Empty />
  return <Card data={channel} />
}
```

**要求**：文件头 + 组件注释必加；复杂 Props 可写在解构参数内逐个注释。

## 2. Hook（use*.ts）

```ts
/**
 * @file useDebounce 防抖 Hook
 * @description 将高频变化的值延迟返回，用于搜索框等场景
 * @author 张三
 * @date 2026-10-07
 */

/**
 * @description 返回防抖后的值
 * @param {T} value - 原始值
 * @param {number} [delay=300] - 延迟毫秒数
 * @returns {T} 防抖后的值
 */
export function useDebounce<T>(value: T, delay = 300): T { ... }
```

**要求**：文件头 + 函数注释必加；入参、返回值写清。

## 3. 工具函数（utils / lib / *.ts）

```ts
/**
 * @description 格式化金额：保留两位小数并加千分位
 * @param {number} amount - 金额数值
 * @param {string} [currency='¥'] - 货币符号
 * @returns {string} 格式化结果，如 ¥1,234.50
 */
export function formatMoney(amount: number, currency = '¥'): string { ... }
```

**要求**：函数注释必加；无文件头需求，但纯工具文件建议加一句文件级说明。

## 4. 接口请求（api/*.ts）— 额外写异常

```ts
/**
 * @description 获取用户列表
 * @param {UserQuery} params - 分页与筛选参数
 * @returns {Promise<PageResult<User>>} 分页结果
 * @throws {ApiError} 网络错误或 4xx / 5xx / 业务 code ≠ 0
 */
export async function fetchUsers(params: UserQuery): Promise<PageResult<User>> { ... }
```

**要求**：函数注释 + `@throws` 必加；说明错误何时抛出（HTTP 层还是业务层）。

## 5. Store（stores/*.ts，zustand）

```ts
/**
 * planeStatusStore.ts —— 无人机状态 store：承载 queryPlaneStatus
 * 接口数据（设备列表/集群统计/加载标志）。
 */

export interface PlaneStatusState {
  /** 映射后的设备列表（接口顺序，下标即设备索引） */
  devices: Device[]
  /** 首帧是否已加载完成（面板空态判断依据） */
  loaded: boolean
  /** 拉取并应用最新状态（失败时仅记录错误，不清空数据） */
  refresh: () => Promise<void>
}

export const usePlaneStatusStore = create<PlaneStatusState>((set) => ({
  // 初始空列表：首帧数据由 usePlaneStatusInit 拉取接口填充
  devices: [],
  ...
}))
```

**要求**：文件头一句话写清「存什么数据、谁写入谁消费」；State 每个字段加 `/** */`；action 写触发时机。

## 6. 类型 / 数据文件（types / xxxData.ts）

```ts
/** 选区矩形（局部坐标，px） */
type SnipRect = { x: number; y: number; w: number; h: number }

/** 视频通道静态演示数据：名称/电量/遥测项（接真实流后由后端驱动） */
export const VIDEO_CHANNELS: VideoChannel[] = [...]
```

**要求**：接口/type 上方一句话；mock 数据注明「演示用，接真实数据后移除」。

## 7. 样式（.css / .less）

```css
/* 列表卡片：桌面端三列，移动端单列 */
.user-card { display: grid; grid-template-columns: repeat(3, 1fr); }

/* 视频画面：object-fit 裁切居中，容器黑边由 shade 遮罩 */
.vm-video-stream { width: 100%; height: 100%; object-fit: cover; }
```

**要求**：区块级短注释写「布局方式 / 响应式断点」；显而易见的属性不注释。

---

## 8. 配置 / 常量（config / *.ts）

```ts
// 主题色统一配置：组件禁止写死色值
export const COLORS = { primary: '#1677ff', danger: '#ff4d4f' }

// 轮询间隔（毫秒）：无人机状态 2s / 告警 5s
export const POLL_INTERVAL = { planeStatus: 2000, alarm: 5000 }
```

**要求**：常量组一句话写用途；带单位的写明单位。

---

## 9. 行内逻辑 — 写「原因 / 边界」

```ts
// 防抖：避免输入过快触发多次请求
// 边界：amount 为 NaN 时直接返回 '--'
// 倒计时进行中忽略重复点击，避免重新计时
```

**要求**：只注释关键分支、边界和「为什么」，不复述代码。

---

## 快速对照表

| 文件类型 | 必加注释 | 最低要求 |
| --- | --- | --- |
| 组件 .tsx/.jsx | 文件头 + 组件注释 | 功能、Props |
| Hook use*.ts | 文件头 + 函数注释 | 功能、入参、返回值 |
| 工具/接口 utils·api | 函数注释 | 参数、返回、异常 |
| Store stores/*.ts | 文件头 + 字段注释 | 存什么、谁消费 |
| 类型/数据文件 | 声明上方一句话 | 用途、是否 mock |
| 样式/配置/常量 | 单行/短块注释 | 用途一句话 |
| 复杂行内逻辑 | 行注释 | 分支、边界、原因 |

> 注释随代码一起更新：改代码时同步改注释。
