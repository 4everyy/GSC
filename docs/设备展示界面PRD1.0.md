# 页面背景

本页面为设备监控核心列表页，用于实时呈现所有接入设备的在线状态、类型及基础电量等信息，支持多维度筛选与详情查看。

# 全局说明与非功能性需求

 空状态：无数据时显示占位图，文案为“当前条件下暂无设备”

 加载状态：进入页面时，若数据未返回，列表区域展示骨架屏或 Loading 动画。

 缺省状态：若筛选后无数据，展示“暂无数据”缺省图及文案。

 异常处理：若接口请求失败，展示全局Toast提示“网络异常，请稍后重试”，并保留当前筛选条件。

# 排序与分页规则

 默认排序：默认按照“设备名称”首字母 A-Z 排序，在线设备优先排序；

分页逻辑：

若设备数量 < =20 条，不分页，直接展示。

若设备数量 > 20 条，采用无限滚动加载。
