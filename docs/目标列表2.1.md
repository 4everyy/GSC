# 二、概述

# 2.1需求背景

无人机地面站态势页面可实时接收无人机AI识别回传的探测目标数据，包含人员、车辆等目标信

息。为规范操作员作业体验、保证态势地图视野干净整洁，本次采用「地图极简操作+列表精细化管

理」分层设计：态势地图仅提供高频重点目标标记能力，不展示冗余详情；目标完整信息、精细化操作

全部收敛至侧边目标列表。解决传统交互弹窗泛滥、遮挡态势视野、操作混乱的问题，适配安防、巡

检、搜救等作业场景。

# 2.2业务目标

实现目标数据统一展示，支持操作员查看无人机探测目标全量字段信息；

实现地图悬浮快速标记重点目标、列表标记双向联动，状态实时同步；

规范聚合、重叠目标交互边界，杜绝误操作、无效操作；

保障人工标记状态持久化，数据刷新、重连不丢失人工操作结果；

统一交互层级，简化地图操作，提升态势观察效率。

# 2.3名词术语定义

| 术语 | 定义 |
| --- | --- |
| TGT(Target) | 探测目标，无人机识别回传的人、车辆、船只等识别对象 |
| 重点目标 | 操作员人工标记，需要重点关注的探测目标 |
| 目标聚合 | 多个目标坐标临近，地图合并为单个聚合图标展示 |
| Marker | 态势地图上展示的目标点位图标 |

# 三、用户场景

# 3.1典型用户角色

地面站操作员

# 3.2核心使用流程

示例：

场景1：操作员查看全部目标

1.操作员点击界面【目标列表】按钮→抽屉展开，加载所有目标数据

2.可查看序号、类型、经纬度、发现源、发现时间、目标图片

3.点击列表目标条目→地图自动定位至该目标点位

场景2：地图快速标记重点目标

1.鼠标悬浮地图独立目标图标≥300ms→弹出操作气泡

2.点击【标记为重点目标】

3.地图目标图标更新重点样式；目标列表同步更新旗子图标与行高亮

场景3：聚合目标操作

1.悬浮聚合图标仅提示聚合数量，无标记按钮

2.点击聚合图标散开子目标

3.悬浮散开后的独立目标，方可执行标记操作

场景4：列表标记重点目标

1.点击列表旗子图标切换重点状态，列表行高亮、地图Marker同步变更重点样式。

# 六.非功能需求

性能：200条以内目标流畅不卡顿，联动响应≤200ms。

稳定性：数据异常、图片失效、网络波动不崩溃、不报错、保留已有数据。

数据一致性：列表、地图、后台标记状态三者统一，刷新不丢失人工标记。

体验：防抖防误触、无多气泡、无静默操作。
